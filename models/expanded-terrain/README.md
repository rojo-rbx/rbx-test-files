# Expanded Terrain
* Roblox Studio version: 0.745.0.7451137

A `Terrain` (with its `MaterialNames` child) from a place with `Workspace.ExpandedTerrain` enabled, saved with "Save to File".

The voxels are stored inline in `Terrain.VoxelGridAssetContentMap`, which is an `AssetContentMap` with 8 entries and no bundle asset ID. `Terrain.SmoothGrid` only contains a header.
