# Expanded Terrain, published
* Roblox Studio version: 0.745.0.7451137

A place with `Workspace.ExpandedTerrain` enabled and a small amount of terrain. It was published, then downloaded from Roblox.

Once a place is published, Roblox uploads the voxels of `Terrain.VoxelGridAssetContentMap` (an `AssetContentMap`) as a separate bundle asset. The downloaded file only contains the bundle asset ID and no entries. `Terrain.SmoothGrid` only contains a header.

There is no XML version of this file, because XML files cannot hold a bundle asset ID.
